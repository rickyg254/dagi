# dagi

Python-powered interactive pastry ordering app.

## Features

- Product categories included:
  - Soft icing cakes
  - Fondant icing cakes
  - Cupcakes
  - Macarons
  - Cakepops
- Interactive quantity controls with live order summary and total.
- Server-side order validation and quote generation via Flask.

## Run locally

1. Install dependencies:

```bash
python3 -m pip install flask
```

2. Start the app:

```bash
python3 app.py
```

3. Open `http://127.0.0.1:5000` in your browser.
Simple interactive pastry ordering app.
